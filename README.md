## 🌐 내 이름으로 된 무료 인터넷 주소 만들기 (추천)

### 방법 1: GitHub Pages (가장 권장, `아이디.github.io` 주소 생성)
1. [GitHub](https://github.com)에 로그인합니다.
2. 새 리포지토리(New Repository)를 만들 때 이름을 **`yljeong.github.io`** 로 설정합니다.
3. 이 폴더의 `index.html`을 업로드(또는 git push)합니다.
4. 약 1~2분 뒤 **`https://yljeong.github.io`** 주소로 전 세계 누구나 접속할 수 있는 홈페이지가 완성됩니다.

### 방법 2: Vercel / Netlify (원클릭 드래그 앤 드롭)
1. [Netlify Drop](https://app.netlify.com/drop)에 접속합니다.
2. 현재 `MY_PAGE` 폴더를 통째로 마우스로 끌어다 놓습니다.
3. 즉시 무료 고유 인터넷 주소(예: `yonglack-jeong.netlify.app`)가 생성됩니다.
